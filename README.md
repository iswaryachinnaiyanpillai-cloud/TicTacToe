# 🎮 Tic Tac Toe

A simple and interactive console-based Tic Tac Toe game developed using C++.

## 📌 Features

- Two-player gameplay
- Player X and Player O
- 3 × 3 game board
- Input validation
- Prevents occupied positions
- Automatic winner detection
- Draw detection
- Play again option
- Score board
- How to Play instructions
- Simple menu-driven interface

## 🛠️ Technologies Used

- C++
- Standard C++ Library
- MSYS2 UCRT64

## ▶️ How to Run

Compile the program:

```bash
g++ tic_tac_toe.cpp -o tic_tac_toe.exe
